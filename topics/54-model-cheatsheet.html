Data Problem Diagnostic Checklist
  • ✅ Class imbalance? → PR-AUC metric, class weights or SMOTE, threshold tuning
  • ✅ High cardinality categoricals? → target encoding with CV, embeddings, count encoding
  • ✅ Missing data? → add missingness indicator + impute; XGBoost handles NaN natively
  • ✅ Multicollinearity? → check VIF, use Ridge or PCA before linear models
  • ✅ Outliers? → Huber loss for regression; robust scalers; Winsorize at 1st/99th percentile
  • ✅ Data leakage? → features collected after prediction time; always check temporal ordering
  • ✅ Label noise? → label smoothing, robust loss functions, confidence learning (cleanlab)
  • ✅ Distribution shift at serving? → PSI monitoring, trigger retraining when PSI > 0.1
Model selection as a decision procedure
In code
A decision procedure rather than a table: what to reach for first given the shape of the data, and the honest note that a tuned GBM wins most tabular problems.
def pick_model(n_rows, n_features, data_type, needs_explanation=False,
               latency_ms=None, labels='plenty'):
    """A defensible starting point. Not a law -- but say this out loud in an
    interview and you will be right far more often than a hunch."""
    if data_type == 'tabular':
        if needs_explanation:
            return 'logistic regression / scorecard, or a GBM with monotone constraints + SHAP'
        if n_rows < 1_000:
            return 'regularised linear or SVM -- a GBM will overfit this'
        return 'gradient boosting (XGBoost/LightGBM) -- the tabular default'
    if data_type == 'text':
        return ('TF-IDF + linear (fast, strong baseline)' if n_rows < 10_000
                else 'fine-tuned encoder (BERT family), or an API LLM if labels are scarce')
    if data_type == 'image':
        return 'fine-tune a pretrained CNN/ViT -- training from scratch needs ~1M+ images'
    if data_type == 'sequence':
        return 'temporal features + GBM first; transformer only if the baseline loses'
    if data_type == 'graph':
        return 'graph features + GBM first; GNN when structure carries the signal'
    return 'start with the simplest thing that could work'

cases = [
    dict(n_rows=50_000, n_features=80, data_type='tabular'),
    dict(n_rows=50_000, n_features=80, data_type='tabular', needs_explanation=True),
    dict(n_rows=600,    n_features=20, data_type='tabular'),
    dict(n_rows=5_000,  n_features=1,  data_type='text'),
    dict(n_rows=20_000, n_features=1,  data_type='image'),
]
for c in cases:
    print(f"{c['data_type']:8} n={c['n_rows']:<7} -> {pick_model(**c)}")
